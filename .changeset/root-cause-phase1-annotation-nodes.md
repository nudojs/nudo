Type-annotation mapping now has a single object-member model and a structural node path.

- `@nudojs/core`: `ts-type-shape` classifies object members once (`ObjectMember`): index / call / construct / accessor / method / property / computed symbol / `readonly` index. `interface extends` is flattened recursively. A non-enumerable `nudoTypeNode` side channel feeds a `TSType` node mapper (member containers, functions, constructors, unions, tuples); unsupported nodes fall back to text during the migration.
- `@nudojs/core`: `$copy` now transports `Abs.facets` for tuple / array / function / brand / effect / union snapshots, not only objects.
- `@nudojs/service`: `FormalParam.tsTypeNode` / `FunctionAnalysis.declaredReturnTypeNode` carry the annotation node from the strip pass. `FunctionAnalysis.declaredReturnAbs` is resolved at analysis time with named/imported/inline type tables; `tsDeclaredReturn` now keeps the declaration whenever it covers every observed path (`declaredCoversObserved`), plus `this` / `void` declarations. This fixes declaration narrowing for `keyof` / unions / object supertypes / tuples / nested function types. Module dts projection now appends `export {};` when it has no other module marker, so non-exported top-level declarations are no longer implicitly exported. Class surfaces keep `#private;` for private methods and `abstract` on accessors. Class field declarations seed the runtime field domain via `$declDomain` (annotations preserved through the private-name AST copy), so `items: number[] = []` no longer folds to the empty tuple. Constructor writes no longer shadow declared field annotations, constructor param defaults seed the class entry domain, and private field types feed getter observation. Destructured default params may be optional in declaration signatures, same-name namespaces merge members (including ambient namespace implicit exports and `TSDeclareFunction`), and non-exported enums referenced by public signatures are emitted as module-local `declare enum`.
- `@nudojs/core` / `@nudojs/service`: utility types (`Partial` / `Required` / `Readonly` / `Pick` / `Omit`), dotted `typeof` value paths, inline `import("spec").T` annotations and named interface / type-alias nodes map structurally; default/namespace literals share one literal gate, and bigint literal terms render as `10n`.
